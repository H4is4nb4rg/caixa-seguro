# Caixa Seguro — Front-end (Angular)

Interface web responsiva do Caixa Seguro, pensada para uso no celular, no balcão da loja.

```bash
npm install
npx ng serve          # http://localhost:4200
npx ng build          # build de produção em dist/frontend
```

O endereço da API fica em `src/environments/environment.ts` (`apiUrl`).

Telas: login, início (status do caixa), nova movimentação, confirmação e fechamento do caixa.
